Aide - Comment utiliser le Scrabble Solver
  • Remplir la grille : Cliquez sur une case pour la sélectionner, puis tapez une lettre au clavier. Sinon drag & drop depuis le chevalet.
    Majuscule = lettre normale, minuscule = joker (lettre grisée).
  • Utiliser le chevalet : Cliquez sur une case du chevalet et tapez la lettre correspondante.
    Utilisez ? pour un joker dans le chevalet.
  • Effacer une case : Appuyez sur Suppr ou Retour arrière après avoir sélectionné une case.
  • Calculer les coups : Cliquez sur "Calculer" ou appuyez sur Entrée.
  • Vider la grille : Cliquez sur "Vider" pour tout effacer.
  • Charger / Sauvegarder la grille : Cliquez sur "Charger une grille (.txt)" pour importer un fichier texte (format attendu : 15 lignes de 15 caractères — utilisez '.' pour les cases vides, lettres majuscules pour lettres fixées, '?' pour joker). Cliquez sur "Sauvegarder la grille (.txt)" pour télécharger l'état actuel de la grille au même format.
